description: Generate the best ideas for improving this project
argument-hint: [topic]
---

Come up with your very best ideas for improving this project.

**Topic (optional): `$ARGUMENTS`** — if provided, scope every idea to this area. If empty, consider the whole project.

1. **Ground yourself first** — Skim `README.md`, `CLAUDE.md`/`AGENTS.md`, and `git log --oneline -15` so ideas are about THIS project, not generic ones.

2. **Generate 30 ideas** — one-liners, spread across different areas (workflow, reliability, automation, simplification, delight). Don't elaborate yet.

3. **Cut ruthlessly** — reject ideas that are generic, scope drift, already shipped, low-impact, or infeasible. Merge duplicates. Keep only the ones that genuinely excite you.

4. **Expand the survivors** — for each, write: what it is (with real file paths), why it helps, downsides, confidence (0–100%), effort (S/M/L).

Stop there. Do not implement anything — the ideas are the deliverable.
